Esta es la version con estructura clasica:

- `index.html`
- `css/styles.css`
- `js/data.js`
- `js/main.js`
- `assets/birth-logo-black.png`
- `.nojekyll`

## Para verla localmente

Abre `index.html` en tu navegador.

## Para subirla a GitHub Pages

1. Crea un repositorio en GitHub.
2. Descomprime el ZIP.
3. Sube todo el contenido descomprimido a la raiz del repositorio.
4. Verifica que `index.html`, `css`, `js`, `assets` y `.nojekyll` queden en la raiz.
5. Entra a `Settings` > `Pages`.
6. En `Build and deployment`, elige `Deploy from a branch`.
7. Selecciona `main` y `/root`.
8. Guarda y espera unos minutos.

La URL quedara parecida a:

`https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`

No subas el ZIP cerrado como unico archivo. Primero descomprimelo.
