Cómo funciona

Este sistema no busca señalar. Busca ordenar, reparar y aprender.

La conversación cambia cuando el foco deja de ser la culpa y se mueve hacia la responsabilidad. Cada nivel existe para leer el impacto, decidir la acción correcta y abrir una ruta clara de recuperación.

Semáforo

Cuatro niveles para leer impacto, no identidad.

Cada nivel combina nombre, color, tiempo de recuperación y acción concreta. Así nadie depende solo del color para entender qué hacer.

Cómo escala una consecuencia

Áreas

Cada área tiene riesgos distintos y evidencia distinta.

Selecciona un área para ver situaciones comunes, preguntas para líderes, evidencia y señales de recuperación.

Casos prácticos

Cosas que sí pasan en agencia, sin drama y con claridad.

Filtra por área, categoría o nivel para encontrar ejemplos concretos y posibles respuestas.

Ruta de recuperación

La confianza vuelve con evidencia, no con promesas.

La fórmula base convierte cualquier error recuperable en una ruta de acción: reconocer, reparar, aprender y demostrar mejora sostenida.

Guía para líderes

Antes de aplicar una consecuencia, lee el contexto completo.

Un buen criterio combina impacto, frecuencia, intención, evidencia y capacidad real de reparación.
